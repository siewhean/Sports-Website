# Gate C implementation downloads

This branch archives every file offered for download during the Gate C C1 follow-up and C2 preparation work.

## Contents

- `c1/`: C1 follow-up bundle, source patch, format-patch and helper scripts.
- `c2/`: Combined C2 preparation bundle, four individual implementation packs and sequencing/QC documents.
- `SHA256SUMS`: SHA-256 digest for every archived file.

## Release boundary

These files are handoff artifacts, not certification evidence. C2 packages must only be applied after the C1 follow-up has a clean exact-SHA PASS and a fresh independent review with `P0: 0` and `P1: 0`.

Review each patch and script before execution. Do not merge this archival branch into application source solely to retain the downloads.
